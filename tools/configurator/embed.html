React to what visitors choose (optional)

  
The frame reports these events to your page. Each carries the full configuration (state), so it can go straight into an enquiry form.

  

    
EventWhenExtra fields

ctaA button at the end of the summary is usedid, kind, url, total

  

  
The summary buttons come from cta in config.json. A button with "kind": "event" does nothing by itself and only sends cta, so your site can open its own form:

  
window.addEventListener('message', (e) => {
  if (e.data?.source !== 'glimmerfell-configurator') return;
  if (e.data.type === 'cta' && e.data.id === 'quote') openMyEnquiryForm(e.data.url, e.data.total);
});
