# Glimmerfell Projects: adding a project

1. Copy `project-template.html`, rename it (lowercase, hyphens), and replace everything marked ✏️.
2. Put images and video files in `media/`. Until a file exists, the page shows a labelled placeholder with the file name it expects.
3. Add a card for it on `index.html` (the "More projects" block), or make it the featured project.

Media: see the comment block at the bottom of the template. A YouTube or Vimeo share link pasted into `data-video` becomes a player.
The menu and footer for every project page are set in `projects.js`, section 1.
Images: about 2000px wide, under ~500 KB. Self-hosted video: short, H.264 MP4.
